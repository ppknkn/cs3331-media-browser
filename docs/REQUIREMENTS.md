# 需求与验收清单

这是 CS3331 软件工程作业的需求基线。验收结果及证据填写在 `TEST_REPORT.md` 与 `FINAL_REPORT.md`。

| 编号 | 用户需求 / 衍生必要行为 | 计划验收方式 |
| --- | --- | --- |
| R01 | 前端与后端协作，Web 页面访问本机服务 | 运行入口、HTTP 服务测试、浏览器加载 |
| R02 | 打开本地文件夹；原生选择器与路径输入 | picker 接口隔离测试、真实路径浏览器验收 |
| R03 | 子文件夹呈现图集，支持嵌套与面包屑返回 | 临时目录扫描测试、浏览器导航 |
| R04 | 图片浏览、上一张/下一张、键盘与关闭 | 多格式接口测试、浏览器查看器 |
| R05 | 视频播放与拖动进度 | Range/HEAD 测试、浏览器真实短视频播放 |
| R06 | 现代界面与合理体验 | 响应式截图、搜索筛选排序、空与错误状态 |
| R07 | 本地文件只读、选定目录边界 | 文件前后比对、越界与符号链接测试 |
| R08 | 后端错误处理与本机访问边界 | 非法请求、Host/Origin/令牌测试 |
| R09 | Team 开发、评审、测试、修复循环 | 开发日志、评审报告、原始测试输出 |
| R10 | 源码、测试代码、完整测试报告 | 文件清单、可复现测试命令、报告 |

| R12 | 可发表的开发过程、问题与经验总结 | 事实记录与博客稿 |

## 范围说明

- 本地服务读取本机目录，网页负责展示；这不是上传媒体到云端的图库服务。
- 支持识别的文件扩展名与浏览器实际可解码的视频编解码格式是不同的能力，必须在文档和错误提示中说明。
- 原生目录选择需要有桌面会话；自动化测试可通过隔离替身验证选择、取消与错误分支，但不能声称已完成真人点击系统对话框。
- 不做媒体删除、改名、编辑、账号体系或在线播放来源聚合。
- 公共仓库只包含本项目源码、测试与人工生成的测试证据，不包含用户本地媒体、原课程应用数据或账号凭据。
